# Contributing

Thank you for contributing to LibreAssistant Mobile.

## Development
1. `corepack enable`
2. `pnpm install`
3. Run `pnpm typecheck && pnpm lint && pnpm test`

## Standards
- TypeScript strict mode
- No hardcoded secrets
- Keep business logic outside UI components
- Add tests for core behavior changes

## Commit and release
- Use Changesets for versioning.
- Keep PRs focused and reviewed.
